# DANI GYM — Fase 1
App móvil/PWA de entrenamiento personal.

Incluye:
- Peso inicial 103,6 kg y objetivo 85 kg.
- Dashboard HOY.
- Rutinas de pecho/tríceps, espalda/bíceps, piernas y core.
- Explicaciones de máquinas, colocación y errores comunes.
- Registro de peso/repeticiones por serie.
- Progresión sugerida.
- Cardio progresivo orientado a llegar a correr 1.000 m.
- Feedback fácil/normal/duro.
- Historial local.

Para usarla: abre index.html. Para instalarla como app en el móvil hace falta servirla por HTTPS (por ejemplo GitHub Pages/Cloudflare Pages).
